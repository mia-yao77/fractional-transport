# 文献笔记：每篇一页

命名：`YYYY-第一作者-关键词.md`，例如 `2000-Metzler-random-walk-guide.md`。

每篇只写一页，必须回答三问：

1. **它解决什么问题？**（一句话，用你自己的话）
2. **它的致命缺点是什么？**（至少要挑出一个；挑不出说明还没读懂）
3. **它和我什么关系？**（我用它的模型 / 我反对它的假设 / 它给了我一个算例）

## 模板

```markdown
# 作者 (年份) 标题
- 出处：
- 读到哪里（页码/章节）：
- 一句话结论：

## 它解决什么问题

## 它的致命缺点

## 它和我什么关系

## 可以直接用的东西
- 公式：
- 算例/数据：
- 引用它的理由：
```
