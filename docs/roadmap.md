## 五句话（v0，2026-11-10）

1. **领域**：地下水中的污染物运移常不服从 Fick 定律（穿透曲线长拖尾、早到、弥散度尺度依赖），称为反常扩散。
2. **缺陷**：分数阶模型能拟合，但阶数物理意义不唯一；不同分数阶模型缺乏系统比较；参数与观测设计的关系无人说清。
3. **问题**：在什么观测条件下，分数阶模型中的阶数 α、β 能被数据唯一确定？
4. **方法**：高精度/快速正演（L1 格式 + 谱方法）+ 统计反演与可辨识性分析（相对 L2 距离、profile likelihood、贝叶斯 MCMC）。
5. **交付**：先一篇「可辨识性与观测设计」，再做变阶反演，最后落到饱和-非饱和 Richards 的应用。
