# 可辨识性实验设计单

> 照这张单子执行，**不再做设计决策**。阈值事先写死，事后不得修改。

## 参数与设置

| 项目 | 设定 |
|---|---|
| 待反演参数 | α（空间分数阶）、β（时间分数阶）、v（流速）、D（弥散系数） |
| 参数网格 | α, β ∈ [0.3, 1.0]，步长 0.05（15×15 = 225 组正演）；v、D 先固定 |
| 正演 | `ft.solvers.solve_fade_1d`；nx=400，dt 由 CFL=0.4 反算 |
| 观测设置 | 下游 1 / 3 / 5 个断面；噪声 1% / 5% / 10%（高斯，相对误差） |
| 距离度量 | 相对 L2：`ft.stats.metrics.relative_l2(reference, curve)` |
| 判定阈值 | **相对差异 < 2% → 实践上不可辨识** |
| 随机种子 | 写在 `config.toml` 的 `[output].seed`，禁止裸 `np.random` |

## 输出

| 图 | 内容 | 必须能回答的问题 |
|---|---|---|
| `fig5_acceptance.png` | α–β 平面上的可接受区域等高线 | 区域是"圆点"还是"斜脊"？斜脊方向说明谁在替换谁？ |
| `fig6_design.png` | 观测断面数 × 噪声 的多面板 | 断面从 1 增到 5，区域缩小几倍？规律可外推吗？ |

## 代码结构

```
experiments/identifiability/
├─ config.toml       ← 只改这里
├─ run.py            ← 入口：先 --dry-run，再正式跑
└─ results/          ← 输出：csv + 图（不进 git）
```

## 验收断言（写进 tests/）

1. α→1、β→1 时结果回到经典 ADE，与解析解相对误差 < 1e-2；
2. 225 组正演全部成功、无 NaN；
3. 区域内至少 2 组参数（否则"不可辨识"无从谈起，应检查网格或阈值）；
4. `make figures` 能从零重建两张图。
